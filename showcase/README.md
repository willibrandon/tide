# Tide — a quieter place to think

Sea-glass teal for actions. Amber for structure. Blue-slate surfaces that recede.

## Review the details

- Open `tide.ts`, `Tide.cs`, `tide.py`, `tide.rs`, and `tide.go` side by side.
- Compare TextMate and semantic coloring by toggling semantic highlighting.
- Find `reading`, select a block, inspect brackets, and fold a method.
- Compare `diff/before.ts` with `diff/after.ts`, both inline and side by side.
- Review diagnostics, hover text, completion lists, breadcrumbs, and focus outlines.

**Strong text** establishes structure; *emphasis* changes color without italics.
Links such as [the VS Code theming reference](https://code.visualstudio.com/api/references/theme-color)
remain distinct, and `inline code` uses the string role.

> Calm is a hierarchy, not a lack of color.

The files are self-contained examples. Language services for C#, Python, Go, and
Rust require their usual extensions. The automated grammar checks use pinned
grammars and do not require language servers.
