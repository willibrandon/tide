# Changelog

## 0.1.0 — 2026-09-13

- Introduce Tide Dark and Tide Light: teal actions, amber types, periwinkle
  keywords, sage strings, and neutral blue-slate workbench surfaces.
- Generate both variants from shared workbench, TextMate, and semantic roles.
- Cover modern workbench, agent/chat, diff/merge, notebook, testing, debug,
  terminal, and SCM surfaces against VS Code 1.137.0's pinned source registry.
- Enforce 4.5:1 normal-size text contrast, including code over diff highlights,
  plus 3:1 essential indicator contrast with alpha-composited background stacks.
- Reject unknown UI keys, unclassified additions, semantic italics, theme
  parity drift, stale generated output, and mismatched release versions.
- Add grammar-role regression checks, a real-editor preview/capture workflow,
  package-content validation, and installable VSIX artifacts with checksums.
